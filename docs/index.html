Latent-Space Speculative Decoding

Draft the next N tokens as latent vectors in one pass, verify them with exact accept/reject sampling. Interactive lab · simulator mode

The cycle (one target forward pass per cycle)

pending token y→layers 1…L (intermediate)→draft head: hL, emb(y) ⇒ N latents→frozen LM head ⇒ N draft tokens→layers L…end verify [y, d₁…dN] in parallel→accept/reject: u < p/q→emit k+1 tokens, roll back KV
The same pass that verifies cycle t exposes the hidden state used to draft cycle t+1, so drafting adds no extra model pass.
